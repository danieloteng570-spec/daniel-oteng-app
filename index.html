What is a Computer?

A computer is an electronic device that receives data, processes it and produces information.

Computer Hardware

Hardware refers to the physical parts of a computer, such as the keyboard, mouse, monitor and printer.

Computer Software

Software is a set of instructions that tells a computer what to do. Examples include operating systems and apps.
